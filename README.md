# Food Delivery Management SQL Project

## Project Overview

This project focuses on analyzing a Food Delivery Management database using MySQL. The objective is to transform raw business data into meaningful insights related to customers, restaurants, menu items, orders, payments, and delivery operations.

The project demonstrates how SQL can be used to solve real-world business problems through data analysis and reporting.

---

## Business Scenario

A food delivery platform connects customers with restaurants and facilitates online ordering, payments, and deliveries.

As the business grows, management requires data-driven insights to better understand customer behavior, restaurant performance, order trends, payment outcomes, delivery operations, and product demand.

This project aims to support decision-making by analyzing operational data stored in a relational database.

---

## Business Objectives

- Understand customer behavior and engagement.
- Analyze restaurant and cuisine performance.
- Evaluate order trends and purchasing patterns.
- Assess payment and delivery effectiveness.
- Identify high-demand menu items and product categories.
- Generate actionable business recommendations.

---

## Dataset Overview

The database consists of the following tables:

| Table | Records |
|---------|---------:|
| Customers | 500 |
| Restaurants | 40 |
| Menu Items | 300 |
| Orders | 2000 |
| Order Items | 5000 |

---

## Database Structure

The project uses a relational database containing five major tables:

- Customers
- Restaurants
- Menu Items
- Orders
- Order Items

### Key Relationships

- One Customer can place many Orders.
- One Restaurant can receive many Orders.
- One Restaurant can offer many Menu Items.
- One Order can contain many Order Items.
- One Menu Item can appear in many Order Items.
